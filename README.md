# Кафе «Дача для друзей» — сайт, QR-меню и админка

Сайт кафе в Снежинске с упором на меню: доставка и самовывоз, QR-меню на каждом столе (заказ по гостям, раздельная оплата, вызов официанта), заказы в Telegram и админка со стоп-листом и ценами.

Всё работает на одном маленьком Node.js-сервере: без базы данных, без сборки фронтенда, одна зависимость (`qrcode`).

## Что есть

| Адрес | Что это |
|---|---|
| `/` | Сайт: меню, доставка и самовывоз, залы и банкеты, отзывы, контакты, бронь стола |
| `/t/<код стола>` | QR-меню. Каждый стол имеет свой QR-код и открывает меню со своим номером |
| `/admin` | Админка: заказы, стоп-лист, меню и цены, столы и QR, дачные обеды, настройки |
| `/privacy` | Политика конфиденциальности (текст задаётся в админке) |

### QR-меню на столе

- Гость сканирует код и вводит имя. Друзья за столом добавляются как отдельные гости.
- Блюдо добавляется за конкретного гостя или «на всех» (стоимость делится поровну между выбранными).
- «Отправить официанту» — заказ приходит в Telegram с разбивкой по гостям, с кнопкой «Принять».
- «Счёт» показывает, сколько должен каждый гость.
- «Готовы оплатить»: раздельно или одним чеком, способ (наличные, карта, СБП), чаевые. Официант получает уведомление.
- «Официант»: кнопка вызова (подойти, принести счёт, приборы, убрать со стола, детский стульчик). Статус «идёт к вам» гость видит на экране.
- Стоп-лист работает сразу: закончившееся блюдо серое, заказать его нельзя (сервер проверяет это ещё раз).
- Разные QR-коды могут открывать разные наборы разделов (например, детское меню в детской зоне).

> Оплата происходит у официанта или курьера. Сайт не списывает деньги и не принимает карту онлайн: он только передаёт выбор гостя. Онлайн-оплату (ЮKassa, СБП-эквайринг) можно подключить отдельно.

## Быстрый старт

Нужен Node.js 22 или новее.

```bash
npm install
npm start
```

Откройте `http://localhost:3000`. При первом запуске в консоли напечатается пароль администратора. Сохраните его: показывается один раз. Задать свой пароль можно через `ADMIN_PASSWORD` в `.env` или сменить в админке (Настройки → Пароли). Забыли пароль — остановите сервер и выполните `npm run reset-password -- НовыйПароль`.

Меню, залы, часы работы и контакты уже заполнены по текущему сайту кафе (дачакафе.рф). Проверьте и поправьте их в админке.

## Подключение Telegram (5 минут)

1. В Telegram откройте **@BotFather**, отправьте `/newbot`, придумайте имя и скопируйте токен.
2. Создайте группу для персонала (официанты, бар, кухня) и добавьте в неё бота.
3. Напишите в группе `/id` — бот ответит номером чата (вида `-1001234567890`).
4. В админке: **Настройки → Telegram**. Вставьте токен и номер чата, нажмите «Сохранить», затем «Проверить» — в группе появится тестовое сообщение.

Дальше в группу приходят заказы, брони, вызовы и запросы оплаты. Под каждым сообщением есть кнопки («Принять», «Иду», «Оплачено», «Передан курьеру»…). Нажатие меняет статус и обновляет сообщение, а гость видит это на своём телефоне. Те же кнопки есть в админке.

Если Telegram недоступен, заказ всё равно сохраняется, а сервер повторяет отправку несколько часов. Неотправленное видно в админке с кнопкой «Отправить снова».

Доставку можно слать в отдельный чат (поле «Чат доставки»).

### Если Telegram блокируется

Сервер должен достучаться до `api.telegram.org`. Если хостинг его не пропускает:
- возьмите сервер за пределами РФ, либо
- поднимите прокси к Bot API и укажите его адрес в `TELEGRAM_API_BASE`, либо
- задайте стандартные переменные прокси и запустите с `NODE_USE_ENV_PROXY=1` (Node 22.21+).

## Админка

Администратор видит всё, **повар** (отдельный пароль) — только стоп-лист. Работает и на телефоне.

- **Заказы** — столы прямо сейчас (гости, сумма, кто зовёт официанта) и журнал: столы, доставка, брони, вызовы, оплата. Кнопки статусов. Можно включить звук нового заказа.
- **Стоп-лист** — большие переключатели «Есть / Стоп», поиск, «весь раздел в стоп», «снять всё».
- **Меню и цены** — цену меняете прямо в списке: введите число и нажмите Enter, гости увидят её сразу. Карточка блюда: фото, описание, вес, пометки, варианты («лапша на выбор»), скрыть или удалить. Массовое изменение цен (на %, на сумму, с округлением и предпросмотром). Управление разделами и временем их доступности. Кнопка «Сохранить фото на сервер» скачивает картинки блюд, чтобы не зависеть от старого сайта.
- **Столы и QR** — залы, столы, наборы меню для разных QR-кодов, печать табличек (A4, по 4 на лист), QR для сайта и доставки.
- **Дачные обеды** — списки салатов, супов и горячего на сегодня; подставляются в комплексы.
- **Настройки** — контакты, часы работы, доставка (бесплатно от суммы, стоимость, минимальный заказ, пауза приёма), способы оплаты, чаевые, промокоды, Telegram, пароли, банкетные цены, текст политики конфиденциальности.

## Как напечатать QR-коды

Админка → **Столы и QR** → «Печать табличек». Перед печатью проверьте, что адрес в QR настоящий: откройте админку по боевому адресу (`https://ваш-домен/admin`) или задайте `PUBLIC_URL`. QR-коды с адресом `localhost` на других телефонах не откроются.

Если QR стола попал не в те руки, в карточке стола есть «Выпустить новый QR-код»: старый перестанет работать.

## Развёртывание на сервере

Подойдёт любой VPS (Linux) с Node.js 22.

```bash
git clone <репозиторий> /opt/dacha && cd /opt/dacha
npm ci --omit=dev
cp .env.example .env     # укажите PUBLIC_URL и пароль
```

Запуск как службы (`/etc/systemd/system/dacha.service`):

```ini
[Unit]
Description=Dacha cafe
After=network.target

[Service]
WorkingDirectory=/opt/dacha
ExecStart=/usr/bin/node server.js
Restart=always
User=www-data
Environment=NODE_ENV=production

[Install]
WantedBy=multi-user.target
```

HTTPS нужен обязательно (QR открывают с телефонов). Проще всего Caddy, он сам получит сертификат:

```
dacha.example.ru {
    reverse_proxy localhost:3000
}
```

и добавьте в `.env`: `PUBLIC_URL=https://dacha.example.ru` и `TRUST_PROXY=1`.

Через Docker:

```bash
docker build -t dacha .
docker run -d --name dacha --restart=always -p 3000:3000 -v dacha-data:/data --env-file .env dacha
```

### Данные и резервные копии

Всё лежит в папке `data/` (или `DATA_DIR`): `config.json` (меню, столы, настройки, хеши паролей), `runtime.json` (заказы и открытые столы), `uploads/` (фото). Копируйте её раз в сутки. Для переноса на другой сервер достаточно перенести папку.

## Что стоит проверить перед запуском

Пока не было других данных, я взял значения со старого сайта и добавил разумные по умолчанию. Эти места нужно сверить:

- **Воскресенье:** на сайте режим не указан, стоит 11:00–23:00.
- **Доставка:** условие «бесплатно от 1000 ₽» взято с сайта. Стоимость 150 ₽ при заказе меньше 1000 ₽, время «60–90 минут» и остановка приёма за 30 минут до закрытия поставлены для примера.
- **Столы:** 14 столов в четырёх залах (по данным вместимости с сайта). Расстановка примерная.
- **Позиции без цены на старом сайте** (фокачча классик, пицца «Диабло», каннеллони с говяжьими хвостами, свиные рёбра барбекю) скрыты. Укажите цену — появятся в меню.
- **Нет в меню:** напитков, стейков, пельменей и халуми (гости упоминают их в отзывах): на старом сайте этих позиций не нашлось. Добавьте в админке; раздел «Напитки» уже создан.
- **Кусочек Японии:** на сайте в этом разделе только вок и жареный рис, роллов нет.
- **Дачные обеды:** список на 22.10.2026 перенесён с сайта. Гарнир и напиток в комплексах отмечены «по желанию»: уточните, входят ли они в цену.
- **Промокод ДАЧА10** найден в коде старого сайта, но выключен. Включите в Настройках, если он действует.
- **Политика конфиденциальности:** показывается краткий типовой текст. Замените его текстом вашей организации (Настройки).
- **Банкетные цены** показаны без пояснения «за что» (на сайте это не указано).

## Тесты и устройство проекта

```bash
npm test
```

Тесты проверяют расчёт счёта по гостям, часы работы (в том числе после полуночи), заказ за столом, стоп-лист, оплату, доставку, бронь, права доступа и Telegram (на поддельном сервере Bot API).

```
server.js            точка входа
lib/                 сервер: заказы, меню, Telegram, админ-API, хранилище, авторизация
public/              сайт, QR-меню и админка (Preact + htm без сборки, шрифты внутри)
public/js/common/    общий код: счёт, часы работы, меню, компоненты
test/                тесты
data/                данные (создаётся при запуске, в git не попадает)
```

## Безопасность

- Цены в заказе всегда пересчитывает сервер: подмена цены в браузере ничего не даёт.
- QR-коды столов содержат случайный код, угадать чужой стол нельзя. Лимиты запросов считаются на стол, а не на IP: в кафе все гости сидят на одном Wi-Fi.
- Админка закрыта паролем (хеш scrypt), вход ограничен по числу попыток, cookie `HttpOnly`.
- Токен Telegram хранится только на сервере и не отдаётся в браузер.
- Не открывайте папку `data/` наружу: в ней хеши паролей и заказы с телефонами гостей.

## Демо на GitHub Pages

Папка `docs/` — статическая демо-версия сайта и QR-меню без сервера: заказы, вызов официанта и оплата в ней имитируются в браузере, в Telegram ничего не уходит. Админки в демо нет. Пересобрать после правок: `node scripts/build-demo.js /имя-репозитория`.
